# Roadmap

## Phase 1: Admin Shell

- Replace starter Vue UI.
- Add login screen.
- Add protected layout with sidebar and top bar.
- Add overview dashboard.
- Add API client and auth session handling.

## Phase 2: Operations Tables

- Delivery missions.
- Merchant sub-orders.
- Hubs and relay parcels.
- Returns.
- Settlements.
- Notifications.

## Phase 3: Safe Actions

- Pause/unpause rider.
- Reassign/cancel mission.
- Resolve delivery problem.
- Update hub control state.
- Confirm return receipt.
- Trigger refund.
- Set merchant commission override.

## Phase 4: Audit And Reporting

- Add timelines on detail pages.
- Add exportable reports.
- Add audit log views.
- Add role management if backend supports it.

## Phase 5: Production Hardening

- Permission-gated UI.
- Request IDs and traceability.
- Error reporting.
- Analytics for admin actions.
- Deployment for `admin.sequoservices.com`.
